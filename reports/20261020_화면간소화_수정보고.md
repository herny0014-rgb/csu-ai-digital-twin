## 1. 삭제한 영역

| 영역 | 삭제 범위 |
| --- | --- |
| AI 학습용 데이터 수집 | 설명 문구, 수집 시작·종료, 우수 운전 표시, 초기화 버튼, 수집 상태·건수, CSV 다운로드, 5초 자동 수집 |
| 회사 실제 운전 데이터 입력 | 접이식 영역 전체 (기본정보·작업시간·계측값·특이사항 입력, 저장 버튼, 안내 문구) |
| 실시간 운전 데이터 | 제목과 6개 지표 (하역량, 브랜드 기준 일 하역량, 실제 누적 하역량, 버켓 모터 부하, 버켓 토크, 호퍼 로드셀) |

## 3. 유지한 것

- **컨베이어 실시간 운전 데이터** (BOOM / FEEDER / GANTRY): 제목과 지표 모두 유지
- 슈트 막힘 모니터, 원료 이송 흐름도, 사행·편적 AI 예방감시, 컨베이어 속도 제어
- 하역량·부하·토크·호퍼 계산식과 `actual_unloaded_tons` 등 시뮬레이션 상태값 (다른 화면에서 사용)
- 흐름도 안의 "브랜드 기준 일 하역량", "실제 누적 하역량" 표시 (다른 영역이므로 삭제 안 함)
- 수동/AI 자동 모드, 조업 착수 버튼 (별도 작업)
- 데이터 파일과 `archive_prev_v4/` 기존 파일 (삭제 없음)
