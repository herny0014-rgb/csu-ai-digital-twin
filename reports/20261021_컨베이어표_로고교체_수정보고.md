## 1. 컨베이어 실시간 운전 데이터 → 표

| 설비 | 벨트 속도 (%) | 모터 부하 (%) | 토크 (%) |
|---|---:|---:|---:|
| BOOM BC | 값 | 값 | 값 |
| FEEDER BC | 값 | 값 | 값 |
| GANTRY BC | 값 | 값 | 값 |

- 설비는 행, 지표는 열로 고정했다. 단위는 열 제목에만 표시하고 수치는 모두 소수점 한 자리이다.
- 카드 9개와 설비명 반복을 없애 세로 길이가 크게 줄었다 (넓은 화면 기준 약 257px).
- 어두운 배경에 맞춰 열 제목은 밝은 하늘색 배경, 수치는 흰색 굵은 글씨, 줄마다 음영을 넣었다.
- 상태 표시를 제목 옆에 넣었다. 실행 전 **시뮬레이션 대기**(주황), 실행 중 **시뮬레이션 실행 중**(초록).
- "시뮬레이션 값이며 실제 설비 계측값이 아닙니다" 안내는 유지했다.
- 수치 계산식과 1초 단위 갱신은 그대로이다. 대기 상태도 같은 표를 쓰므로 대기용 카드 코드를 없앴다.
- 표 높이는 내용에 맞춰 자동으로 조절된다.

## 2. 상단 로고 교체

- 첨부 이미지(POSCO / 포스코플로우)를 `static/posco_flow_logo.png`로 복사했다. 앱은 `streamlit_app.py` 기준 상대 경로로 읽으므로 임시 파일 경로에 의존하지 않는다.
- 이미지를 그대로 사용했다. 글자·색·배경을 바꾸거나 텍스트로 다시 만들지 않았다. 가로세로 비율도 원본과 같다 (원본 186×94, 화면 150×75.8, 비율 1.979 동일).
- 넓은 화면에서는 왼쪽에 로고, 가운데에 제목을 둔다. 폭이 860px 이하이면 로고 위, 제목 아래 세로 배치로 바뀌고 제목 글자는 조금 작아진다.
- 로고와 제목 사이 여백을 조금 늘렸다 (헤더 아래 여백 0.45 → 0.9rem).
- 이미지 파일을 못 읽으면 로고 자리만 비고 앱은 정상 동작한다.

## 5. 알게 된 점 (이번 범위 밖이라 수정하지 않음)

- 좁은 화면에서 **원료 이송 흐름도**는 레이아웃이 고정 폭이라 아래쪽 타일이 잘리고 줄바꿈이 어색하다. 이번 요청 범위가 아니라 그대로 두었다.
- 표의 수치는 시뮬레이션 설정값 주변에서 조금씩 움직이므로, 흐름도 오른쪽 패널의 설정값(예: 80 / 84 / 86)과 소수점 이하 또는 ±3 정도 차이가 난다. 기존과 같은 동작이다.
- 넓은 화면에서는 표가 가로로 길게 펼쳐져 행 이름과 수치 사이 간격이 넓다. 필요하면 표 최대 폭을 제한할 수 있다.

## 7. 추가 수정 — 로고를 화면 색에 맞춤 (2026.10.21)

- 흰 배경 로고가 어두운 화면에서 튀어서, **`static/posco_flow_logo_dark.png`**를 새로 만들어 사용한다. 원본 `posco_flow_logo.png`는 그대로 보관한다.
- 만드는 방법: 원본의 흰 배경을 투명하게 하고, 글자 모양(가장자리 부드러운 정도 포함)은 그대로 둔 채 글자색만 화면 글자색(`#eef7fc`)으로 바꿨다. 글자 모양·비율은 바꾸지 않았다.
- 이미지 안쪽 여백을 잘라 로고 왼쪽 끝이 "브랜드 선택" 제목 왼쪽 끝(24px)에 맞게 했고, 3배로 키워 선명하게 했다. 가로세로 비율은 이미지와 화면이 같다 (2.357).
- 표시 크기는 가로 120px로 줄여, 이전과 비슷한 글자 크기로 보이게 했다.
- 앞서 "글자 색을 바꾸지 말라"는 지시가 있었으나, 이번에 화면과 색을 맞추라는 요청에 따라 색을 바꾼 것이다. 원본 색이 필요하면 코드의 파일 이름 한 줄만 되돌리면 된다.
