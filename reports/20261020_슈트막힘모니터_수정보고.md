# 수정 보고 — 슈트 막힘 모니터 추가

> ※ 이 문서는 해당 단계 작성 당시의 기록입니다. 이후 화면이 다시 바뀌었고, 커밋·푸시·배포 항목은 당시 상태입니다. **최종 구현 상태와 저장·배포 결과는 `20261021_최종_작업보고.md`를 기준으로 합니다.**

- **구분:** 기능 추가 (로컬 커밋만, 푸시·배포 없음)
- **근거:** V5 PoC 범위 정정본 (슈트 막힘·청소만 반영, 사행·돌발정비·계획정비 제외)

## 1. 수정 내용

화면 하단 "회사 실제 운전 데이터 입력" 아래에 **🚧 슈트 막힘 모니터**를 추가했다.

| 항목 | 내용 |
| --- | --- |
| 입력 | 슈트 막힘 횟수(기본 3회), 막힘·청소 누적 정지시간(기본 45분), 기준 하역률(기본 1,200 t/h) |
| 경고 | 막힘 1회 이상이면 경고 표시, 0회면 "슈트 막힘 없음" |
| 표시값 | 막힘 횟수, 누적 정지시간, 건당 평균 정지시간(15분), 추정 손실량(900 t, 참고용) |
| 계산식 | 추정 손실량 = 기준 하역률 × 막힘 정지시간 |

## 2. 적용 기준

- 입력값은 **가상 설정값**이며 실제 발생 이력이 아니다. 화면에도 표시했다.
- 막힘 손실량은 **기본 하역량(누적 하역량·하역률)에서 차감하지 않는다.** 별도 정보로만 표시한다.
- 손실량은 같은 하역률을 유지했을 때의 기회손실 추정값이며, 실제 미하역량이 아니다.
- 사행, 돌발정비, 계획정비 관련 입력·계산은 추가하지 않았다.

## 6. 남은 사항

- 경고 기준은 "1회 이상"으로 단순하게 두었다. 단계 구분(예: 누적 30분 이상 위험)은 기준값 확정 후 반영.
