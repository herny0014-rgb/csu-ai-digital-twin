## 3. 추천 하역률: 실제 이력 기반인가

**아니다. 가상 조건 기반 참고값이다.**

| 항목 | 상태 |
| --- | --- |
| 브랜드별 최근 2년 실적 (총량, 일 평균) | 앱에 들어 있음 (기존 전달 집계값, 원본 재검증 필요) |
| 브랜드별 슈트 막힘 이력 | **앱에 연결되어 있지 않음** |
| 슈트 막힘 입력값 (3회·45분·1,200 t/h) | **가상 설정값**, 실제 이력 아님 |
| 추천 하역률 | 브랜드별 발표용 운전값을 기존 시뮬레이션 식에 넣은 결과. 실제 이력으로 학습·검증한 값 아님 |
| 막힘 조건의 추천 반영 | 근거에 표시만 하고 추천 수치에는 반영하지 않음 |

화면 표시: 목록 브랜드는 "가상 조건 기반 참고값", 직접 입력 브랜드는 "이력 부족 · 전체 평균 기준 참고값".

실제 추천으로 쓰려면 필요한 것: ① 브랜드별 슈트 막힘 횟수·정지시간·청소 이력 ② 선박별 수분율 ③ 집계 원본과의 대조 ④ 이를 하역률에 연결하는 검증된 로직.

**참고:** 저장소 `herny0014-rgb/csu-ai-digital-twin`은 **공개(Public)** 이다. README에는 회사 관련 화면이라 비공개를 권장한다고 되어 있다. 이번에 로고와 보고서가 공개 저장소에 올라갔다. 공개 범위는 바꾸지 않았다.

## 5. 배포

| 항목 | 상태 |
| --- | --- |
| 기존 배포 방식 | README 기준 Streamlit Community Cloud (저장소 `main`, `streamlit_app.py`). 저장소에 연결된 앱이라면 푸시 후 자동으로 다시 배포된다 |
| 배포 URL | **확인하지 못함.** 저장소에 URL이 적혀 있지 않고, GitHub 명령줄 도구(`gh`)가 없어 연결 정보를 조회하지 못했다 |
| 시도한 것 | 이름으로 추정한 `csu-ai-digital-twin.streamlit.app`을 열어 보니 "Not found"가 나왔다. 앱이 없는 것인지, 비공개 앱이라 로그인 없이 보이지 않는 것인지 구분할 수 없다 |
| 배포 URL에서의 로고·화면·시뮬레이션 확인 | **하지 못함** |
| 새 서비스 생성·공개 범위 변경 | 하지 않음 |

따라서 배포는 **완료로 보고하지 않는다.** 코드는 `main`에 올라가 있고, 실제 배포 앱이 이 저장소를 보고 있다면 자동 재배포되어야 한다.
