## 3. 추천 하역률: 실제 이력 기반인가

**아니다. 가상 조건 기반 참고값이다.**

| 항목 | 상태 |
| --- | --- |
| 브랜드별 최근 2년 실적 (총량, 일 평균) | 앱에 들어 있음 (기존 전달 집계값, 원본 재검증 필요) |
| 브랜드별 슈트 막힘 이력 | **앱에 연결되어 있지 않음** |
| 슈트 막힘 입력값 (3회·45분·1,200 t/h) | **가상 설정값**, 실제 이력 아님 |
| 추천 하역률 | 브랜드별 발표용 운전값을 기존 시뮬레이션 식에 넣은 결과. 실제 이력으로 학습·검증한 값 아님 |
| 막힘 조건의 추천 반영 | 근거에 표시만 하고 추천 수치에는 반영하지 않음 |

화면 표시: 목록 브랜드는 "가상 조건 기반 참고값", 직접 입력 브랜드는 "이력 부족 · 전체 평균 기준 참고값".

실제 추천으로 쓰려면 필요한 것: ① 브랜드별 슈트 막힘 횟수·정지시간·청소 이력 ② 선박별 수분율 ③ 집계 원본과의 대조 ④ 이를 하역률에 연결하는 검증된 로직.
