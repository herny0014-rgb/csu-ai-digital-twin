# CSU AI 하역 디지털 트윈 (POSCO FLOW)

CSU(연속식 하역기) 하역 공정을 시뮬레이션하는 Streamlit 앱입니다. 버켓이 실제 하역기처럼 닫힌 경로를 따라 순환하고, 컨베이어(BOOM / FEEDER / GANTRY BC)로 화물이 이송되는 모습을 보여 줍니다. 수동 운전과 AI 자동 운전을 비교하고, 학습용 운전 데이터를 수집할 수 있습니다.

> 제어기와 AI 추천값은 최근 2년 브랜드별 하역 실적을 바탕으로 만든 **발표용 시뮬레이션**입니다. 실시간 설비 연동은 없습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `streamlit_app.py` | 앱 본체 (단일 파일) |
| `requirements.txt` | 의존 패키지 (`streamlit>=1.37`) |
| `run.bat` | 로컬 실행 스크립트 (더블클릭) |
| `archive_prev_v4/` | 이전 단계 버전 보관용 (버켓이 상하 이동하던 7/27, 7/28 버전) |
| `.git/` | 저장소 이력. GitHub `herny0014-rgb/csu-ai-digital-twin`과 연결됨 |

## 로컬 실행

`run.bat`을 더블클릭하면 됩니다. 처음 한 번 `%LOCALAPPDATA%\csu_venv`에 가상환경을 만들고 패키지를 설치한 뒤 앱을 실행합니다. 가상환경을 OneDrive 밖에 두므로 동기화 문제가 없습니다. 브라우저에서 `http://localhost:8501`을 엽니다.

직접 실행하려면 다음과 같이 합니다.

```cmd
py -m pip install -r requirements.txt
py -m streamlit run streamlit_app.py
```

## 주요 기능

- **운전 모드**: `수동` / `AI 자동`. AI 자동에서는 선택한 브랜드의 추천 운전값(디깅 깊이, 버켓·BOOM·FEEDER·GANTRY 속도)이 적용되고 슬라이더가 잠깁니다.
- **조업 착수 / 정지**: 시뮬레이션 시작과 정지. 수동 모드에서 버켓 속도를 0으로 내리면 컨베이어 잔량 처리 카운트다운(3분) 후 자동 정지합니다.
- **니켈 브랜드 기준**: Gemini, SMT, Karembe, Ouaco, Poya 등 11개 브랜드의 실적과 추천값을 제공합니다. 목록에 없으면 직접 입력하며, 이 경우 전체 평균(19,114 T/D)으로 계산합니다.
- **사행·편적 AI 예방감시**: 컨베이어 속도 불균형을 감지해 BOOM BC 속도를 자동으로 낮춥니다.
- **실시간 운전 데이터**: 하역량, 버켓·컨베이어 모터 부하와 토크, 호퍼 로드셀, 예상 소요시간
- **회사 실제 운전 데이터 입력**: CSU 1호기와 2호기별 실제 계측값을 저장해 학습자료로 누적합니다.
- **AI 학습용 데이터 수집**: 5초 주기로 운전값과 AI 판단을 기록하고, 우수 운전 구간을 표시한 뒤 CSV로 내려받을 수 있습니다.

## 주의

- 수집·입력한 데이터는 **브라우저 세션에만 임시 저장**됩니다. 작업을 끝내기 전에 반드시 CSV를 다운로드하세요.
- 설치된 Streamlit이 `st.components.v1.html` 사용 시 `st.iframe`으로 교체하라는 경고를 냅니다. 현재는 동작하지만 향후 버전에서 제거될 수 있습니다.
