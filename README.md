# CSU AI 하역 디지털 트윈 (POSCO FLOW)

CSU(연속식 하역기) 하역 공정을 시뮬레이션하는 Streamlit 앱입니다. 버켓이 실제 하역기처럼 닫힌 경로를 따라 순환하고, 컨베이어(BOOM / FEEDER / GANTRY BC)로 화물이 이송되는 모습을 보여 줍니다. 브랜드와 슈트 막힘 조건을 고르고 시뮬레이션을 실행하면 참고용 하역률(t/h)을 보여 줍니다.

> 제어기와 AI 추천값은 최근 2년 브랜드별 하역 실적을 바탕으로 만든 **발표용 시뮬레이션**입니다. 실시간 설비 연동은 없습니다.

## 로컬 실행

`run.bat`을 더블클릭하면 됩니다. 처음 한 번 `%LOCALAPPDATA%\csu_venv`에 가상환경을 만들고 패키지를 설치한 뒤 앱을 실행합니다. 가상환경을 OneDrive 밖에 두므로 동기화 문제가 없습니다. 브라우저에서 `http://localhost:8501`을 엽니다.

직접 실행하려면 다음과 같이 합니다.

```cmd
py -m pip install -r requirements.txt
py -m streamlit run streamlit_app.py
```

## 주요 기능

화면은 위에서 아래로 다음 순서입니다.

1. **브랜드 선택**: Gemini, SMT, Karembe, Ouaco, Poya 등 11개 브랜드의 최근 2년 실적을 제공합니다. 목록에 없으면 직접 입력하며, 이 경우 전체 평균(19,114 T/D)으로 계산합니다.
2. **슈트 막힘 이력·조건**: 막힘 횟수, 막힘·청소 누적 정지시간, 기준 하역률을 입력하면 경고, 건당 평균, 추정 손실량(참고용)을 보여 줍니다. 현재 값은 **가상 설정값**이며 실제 과거 이력이 아닙니다.
3. **시뮬레이션 실행**: 버튼을 누르면 선택한 브랜드와 막힘 조건으로 아래 결과를 새로 계산합니다. 다시 누르면 누적값을 처음부터 다시 셉니다. 실행 후 입력을 바꾸면 "다시 실행하라"는 안내가 뜨고, 결과는 마지막 실행 조건 그대로 유지됩니다.
4. **추천 하역률(t/h)과 추천 근거**: 핵심 수치 하나와 근거를 보여 줍니다. 아래 "추천 하역률의 한계"를 참고하세요.
5. **원료 이송 흐름도**: 버켓과 컨베이어 이송을 보여 줍니다.
6. **컨베이어 실시간 운전 데이터**: 설비(BOOM / FEEDER / GANTRY BC)를 행, 벨트 속도·모터 부하·토크(%)를 열로 한 표입니다. 실행 전에는 "시뮬레이션 대기", 실행 중에는 "시뮬레이션 실행 중"으로 표시합니다. 모두 시뮬레이션 값이며 실제 계측값이 아닙니다.

### 추천 하역률의 한계

- 추천 하역률은 **"가상 조건 기반 참고값"** 입니다. 브랜드별 발표용 운전값(`BRAND_AI_PROFILES`)을 기존 시뮬레이션 식에 넣은 결과이며, 실제 슈트 막힘 이력으로 학습·검증한 값이 아닙니다.
- 목록에 없는 브랜드는 "이력 부족 · 전체 평균 기준 참고값"으로 표시합니다.
- 슈트 막힘 조건은 근거 영역에 보여 주지만, **추천 수치에는 반영하지 않습니다.** 브랜드별 슈트 막힘 이력이 앱에 연결되어 있지 않고, 막힘 손실을 기본 하역량에서 차감하지 않는 기준이기 때문입니다.
- 실제 추천으로 쓰려면 Poya 등 브랜드별 슈트 막힘 횟수·정지시간 이력, 수분율, 집계 원본 검증, 그리고 이를 하역률에 연결하는 검증된 로직이 필요합니다.

## 주의

- 화면의 슈트 막힘 값과 추천 하역률은 **가상 조건 기반 참고값**입니다. 실제 이력이나 실제 설비 계측값으로 오인하지 마세요.
- 입력한 값은 브라우저 세션에만 임시 저장되며, 데이터 저장·내려받기 기능은 없습니다.
- 설치된 Streamlit이 `st.components.v1.html` 사용 시 `st.iframe`으로 교체하라는 경고를 냅니다. 현재는 동작하지만 향후 버전에서 제거될 수 있습니다.
